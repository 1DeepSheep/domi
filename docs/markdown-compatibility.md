# Markdown 文件与富文本复制

domi 保存下划线时使用 `<u>文字</u>`，Typora 可直接读取。旧版 `++文字++` 仍能在 domi 中打开；编辑并保存后使用兼容格式。代码块、行内代码、公式和链接地址里的加号保留原意。

需要把整篇文档粘贴到飞书等在线文档时，使用文档工具栏的“复制全文（包含图片）”，再在目标文档中正常粘贴。复制选中的正文也会提供富文本 HTML。不要选择目标应用的“粘贴为纯文本”，该操作会主动去除样式。

富文本保留基础结构与样式：四级和五级标题、分隔线、加粗、斜体、删除线、下划线、链接、列表、表格及单元格换行。最终字体、字号和表格宽度由目标文档的主题与编辑器决定。

飞书可能把粘贴的表格转换为内嵌电子表格。表格数据和基础格式仍可保留，展示与编辑方式遵循飞书本身的规则。

源码复制和富文本复制用途不同。把原始 Markdown 文本直接粘贴到不解析 Markdown 的编辑器时，标记可能显示为文本；需要保留排版时应复制渲染后的正文或使用“复制全文”。
