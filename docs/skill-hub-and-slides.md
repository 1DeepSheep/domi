# Skill Hub 与统一 Slides：实施口径

本文件记录 v0.6.49 的产品约定；发布与安装状态以 GitHub Release 和本机版本为准。

## Skill Hub

- 侧栏名称统一为 **Skill Hub**，保留展开／收起与单一纵向滚动列表；列表限制高度，给近期对话留出空间。
- 不增加“团队技能／我的技能”两套导航。官方与用户 Skill 在同一入口使用，管理窗口说明来源与更新边界。
- **新建 Skill**：关闭管理窗口，直接进入 Codex 原生 `skill-creator` 对话。先询问用途、触发条件、输入输出和成功示例，经用户确认后创建并验证，不改成表单向导。
- 创建后发现新的本机 Skill，会打开未勾选的导入列表，仍由用户选择；不会把其他任务同时创建的 Skill 自动加入。
- **导入 Skill**：先扫描本机 Codex 用户目录与 Agents 用户目录，展示名称、用途、来源、冲突和已加入状态，再导入所选项目。扫描本身不执行 Skill。
- Codex 用户目录中的有效顶层 Skill 原地注册；其他支持位置复制到 Codex 用户目录，保留完整目录资源，不修改原件。
- 官方 Skill 使用 `$domi:name`，用户 Skill 使用自己的调用名和已注册路径。同名官方／用户 Skill 可以共存；用户目录内的歧义名称必须修复后再调用。
- 官方插件随 domi 更新；用户 Skill 独立保存。基于官方 Skill 改写时，应创建个人副本，不直接编辑官方插件目录；升级保护针对个人副本。
- 启动个人 Skill 前重新校验名称、描述与源文件，安全改名保留任务身份。失效或歧义 Skill 显示原因，不静默切换到其他 Skill。
- 技能目录变更仅在现有任务及其启动准备阶段结束后刷新 Codex 连接，不中断正在运行的任务。
- 注册文件损坏或来自不支持的版本时保留原件并明确提示；修改注册前保存上一份备份，不把读取错误当成空技能列表。

## 统一 Slides

- 将演示制作资源、模板、参考规范和 QA 脚本从 `investment-analysis` 独立到 `$domi:slides`。
- 研究、IC memo 或用户 Skill 仍负责领域内容；真正创建或修改演示文稿时叠加 Slides Skill，不削减研究、证据覆盖或思考深度。
- 默认采用已有的外资投行／Morgan Stanley 风格与规定字体，约束信息密度、表格可读性、来源、留白和页面层级。
- 默认交付同源 HTML + PDF；明确要求可编辑 PowerPoint／PPTX 时才额外交付 PPTX。编辑现有 PPTX 可保持可编辑交付；明确“不需要 PPTX”时不生成。
- 用户明确要求保留原模板时不强行覆盖主题，但仍执行内容、字体可用性、溢出和逐页视觉检查。
- 解释、打开旧文件、诊断和明确“不生成”的请求，不误触发制作流程。具有明确指代的后续页面修改沿用当前演示的交付要求。
- 内容映射审计、全页渲染、contact sheet 视觉复核与最终文件哈希绑定均为交付条件；PPTX 还需独立渲染检查。
- QA v3 验证浏览器实际使用的字体，不能仅以 CSS 中声明了字体作为通过依据；缺失时按既定规范处理并明确说明，不能静默替换。
- 缺少必要材料时进入“等待补充”，不消耗自动修正次数、不把问题当成已完成交付；紧接的材料补充沿用格式要求，独立新任务不继承。
- 正式 HTML 必须自包含，不能依赖接收者本机不存在的 CSS、图片、字体或脚本路径。
- 桌面和微信都检查交付文件与 QA 记录，失败最多自动修正一次；仍失败则要求人工检查，不冒充已完成或等待网络发送。

## 保持不变

- 上游研究质量与高深度思考策略不因减少重复上下文而降低。
- 运行中的任务单独显示，不加入待办事项总数；排队及失败待处理项目仍按既有规则计数。
- 升级仅替换应用及官方插件，不覆盖用户资料库、会话、设置和个人 Skill。插件 0.3.21 要求客户端至少 v0.6.49；旧客户端保持其兼容插件。

## 验证入口

- 应用完整检查：`npm run check`
- Skill Hub：`node scripts/skill-hub.test.cjs`
- Skill Hub 实际界面创建、导入与滚动：`npm run test:skill-hub-ui`
- 桌面任务与交付：`node scripts/codex-run-context.test.cjs`、`node scripts/slides-delivery.test.cjs`
- 微信链路：`npm run wechat:check`
- 插件打包契约：`npm run plugin:prepare`
- 插件源码测试：在插件仓库运行 `node --test scripts/*.test.cjs`
- 表格与选中复制实际浏览器回归：`npm run test:markdown-tables`

自动检查不能替代真实用户环境中的验收；正式发布前仍需验证首次新建／导入、升级保留个人副本，以及实际 Slides 的逐页视觉效果。
