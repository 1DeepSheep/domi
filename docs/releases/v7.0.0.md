# domi 7.0.0

客户端与内置插件统一从 7.0.0 开始。此版本改善连接、恢复、确定性执行与阅读体验，保留现有模型选择、证据核验、语义审核和成果完整性要求。

## 稳定性

- PLAUD 连接操作在同一队列内释放隐藏浏览器，避免并发操作争抢登录 Profile；给首次认证探测完整的等待时间，区分连接确认中、临时服务故障和确实需要登录。
- SQLite 保存成功提交后才更新内存缓存。事务失败可安全重试，元数据补丁不再读取所有历史正文。
- Codex 初始化失败后释放失效进程；恢复原任务失败会保留恢复目标。准备阶段支持取消，提交结果尚未确认时保留运行归属，避免重复启动。
- 播客保存任务归属、阶段和重试时间。可复用已校验的文字稿及纪要；归档回执必须匹配本次执行、真实文件哈希和唯一文档索引。

## 速度与 Token

- 新闻 RSS/Atom 由程序执行受控并发采集、ETag/Last-Modified 条件请求、精确 URL 去重与候选缓存。缺失、失败、截断范围明确回传；原文核验与搜索补查继续由模型完成。
- 本地 Markdown 缓存结构与行号，按真实内容哈希和解析规则版本失效。同一任务中未改变的索引避免重复注入；PDF、超预算和未读取材料显式标注，不能当作已读证据。
- 项目、人脉、消息及运行记录复用索引，减少流式更新中的重复查找与排序。
- 待办仅在资料、账本、新闻内容版本、规则版本和时间边界均未变化，且上次结果真实校验通过时复用。跨日期、期限或冷却边界会重新判断。
- 插件增加 SQL 筛选、字段投影、稳定分页和批量实体读取；完整原始材料仍可按需读取。

## 程序化与质量

- 工作流增加按规则版本解析的依赖清单、内容哈希、原子检查点、失败阶段恢复和写后归档回执。
- 待办脚本负责账本合并、去重、冷却、生命周期与并发校验；模型继续负责关联性、行动价值、优先级与日期证据。
- 纪要证据索引校验来源文件、内容哈希及定位，IC Memo 统一结构约定，日程程序检查必填字段、邮箱、时区和起止顺序。
- 机械校验不能替代事实判断、语义编辑或视觉检查。旧飞书主库保留原有读写与核验流程，不使用本地回执冒充完成。

## 视觉

- 使用暖白背景、低饱和强调色、细分隔线和更轻的状态层级。
- 统一界面字体与阅读字体，调整字号、字重、行距、内容宽度和留白。
- 同步打磨对话、输入框、资料表格、文档与设置页，沿用原有主要布局和操作习惯。

## 验证范围

执行客户端构建、隐私与历史扫描、运行时/事务/连接测试、跨仓回执契约测试及 Markdown/Skill Hub 界面回归。新增故障用例覆盖回滚重试、初始化重连、未知提交防重、过期检查点、被修改产物和新闻补查。

局部合成基准（1,000 条、每条约 50 KB 的历史任务）中，元数据补丁的历史正文读取量由约 50 MB 降至 0；这不代表整个模型任务的加速倍数。未用真实业务样本得出统一 Token 节省比例；实际收益取决于重复读取与失败重试占比。

升级延续固定应用标识、资料库路径和 Keychain 服务；安装包只替换应用程序。发布分别提供 Apple Silicon 与 Intel 的签名、公证安装包。
