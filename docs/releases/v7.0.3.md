# domi 7.0.3

修复下划线在 domi 内显示正常，但保存后用 Typora 打开却出现 `++` 的问题。编辑器统一保存为 `<u>...</u>`，仍能读取旧版双加号下划线；编辑和再次打开时保留嵌套的加粗、链接、列表与表格样式。

复制到飞书等支持富文本粘贴的在线文档时，剪贴板提供带内联样式的 HTML。四级、五级章节标题保留层级，分隔线、表格边框与单元格换行继续保留。

下划线转换会保护代码、公式、转义文本及链接地址，避免改坏 C++、自增表达式或网址中的加号；复制内容中的危险链接协议不再进入富文本。

升级 Tiptap 与 YAML 解析器的安全补丁，修复特殊输入可能导致解析耗时异常的问题。

这些格式处理由程序完成，不调用模型，不改写纪要事实。本版本继续内置 domi 插件 7.0.3。
