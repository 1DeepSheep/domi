# v0.6.49 · Skill Hub、统一 Slides 与升级保护

## 产品改进

- 侧栏统一使用 Skill Hub，保留有限高度的滚动列表，不挤占近期对话。
- 新建 Skill 直接进入原生 skill-creator 对话；导入先扫描本机用户 Skill，再由用户勾选。官方与个人 Skill 独立保存，官方升级不覆盖个人副本。
- 独立 `domi:slides` 统一各工作流的演示制作：默认外资投行 / Morgan Stanley 风格、HTML + PDF；明确要求可编辑格式时额外交付 PPTX。
- 桌面与微信执行同一 Slides 交付检查：内容映射、实际渲染字体、逐页视觉检查、最终文件哈希。未通过不再冒充完成；缺材料时等待补充。
- 补齐普通选中复制的兼容处理：旧版下划线重点句不再被复制成标题，表格保留换行与边框，真实标题和源文档不受影响。
- 运行中的任务不加入待办总数，仍单独显示运行状态。

## 升级与稳定性

- 插件缓存也重新验证客户端兼容版本、必需文件和完整性；损坏缓存可重建。
- Skill Hub 注册文件异常不再被空列表覆盖，注册更新保留备份。
- 更新空闲检查包含任务启动准备阶段，避免准备中的任务被重启打断。
- 插件激活与任务启动、恢复读取互斥；运行中的任务不因后台插件切换而丢失连接。
- 编辑器依赖升级到修复安全漏洞的兼容版本，并重新验证实际编辑、表格与复制行为。
- 不改变研究模型、思考深度和质量标准；减少开销仍以按需加载和可失效的证据缓存为主。

## 验证范围

发布需通过完整应用测试、真实浏览器表格与选中复制测试、Skill Hub 创建与导入界面测试、插件测试、隐私检查、运行时依赖审计，以及 arm64 / x64 签名、公证、安装包检查。

本轮针对搜索、PLAUD 首次同步及后续对话、微信重复旧回复和真实附件、连接测试超时、研究缓存与升级回滚做回归核查。自动化测试不能代替每位用户的网络、第三方登录态与在线文档粘贴环境验收。

全文搜索的现有边界：符合条件、已下载的本地 Markdown 正文；PDF 目前仅文件名，过大文件及逐字稿正文不在该索引范围内。本版不宣称新增所有文档格式全文检索。

字体检查会揭示缺失字体，而不是把缺字体视作成功。未指定不可替代字体时可按既定规范明确锁定允许的替代字体；用户指定 Calibri 时不静默替换。

插件 0.3.21 要求客户端至少 v0.6.49。更新不迁移或清空资料库；个人 Skill 应保存为个人副本，不直接编辑官方缓存目录。
