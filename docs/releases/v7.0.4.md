# domi 7.0.4

修复插件检查失败时，任务仍在正常执行，左下角却一直显示“Codex 未就绪”的问题。

- 分开显示 Codex 连接和 domi 插件状态。插件列表暂时读取失败时，保留已经确认的连接状态；依赖插件的任务仍需确认插件可用。
- 检测中使用中性提示，失败提示不再直接展示本机命令路径。模型选择依据连接状态，避免被无关的插件检测异常禁用。
- 为检测、保存设置和连接切换增加结果顺序保护，防止旧请求覆盖新配置的检测结果。
- 使用有限次数的只读状态复查恢复临时异常，不发送模型请求，不安装或移除插件，也不重启正在执行任务的服务。
- 将版本信息读取失败与实际连接失败区分，并记录检测阶段、退出码和超时信息，便于定位后续异常。
- 更新 TOML 配置解析库至 1.7.1，修复特定不完整配置可能导致解析卡住的问题。

客户端版本为 7.0.4，内置 domi 插件保持 7.0.3。更新保留现有资料库、文档、连接设置和任务历史。
